# Changelog

This changelog lists changes made in CrossDink. CrossDink started from CrossInk v1.6.0 and keeps merging CrossInk's development branch; for CrossInk's releases and the changes merged from it, see [CrossInk's changelog](https://github.com/uxjulia/CrossInk/blob/development/CHANGELOG.md).

## [Unreleased]

### Added
- Rotate Page 180° can be assigned to the power button, button chords, front-button long presses and long-press menu actions as well as the side buttons, on the device or in web settings (EPUB and TXT readers).
- Touch: swipe left on a File Browser row, a Library list row or a bookmark to reveal a delete button; deleting still asks for confirmation. A tap elsewhere or a swipe right hides it. The Library cover grid keeps paging with horizontal swipes.
- Sync Server: **Server Type** (CrossPoint, KOSync, Other) picks which optional fields are exchanged: CrossPoint and Other send exact book positions, Other also sends ISBN/ASIN/series when Send Metadata is on, KOSync sends standard progress only. Existing setups keep their behavior (default server: CrossPoint, custom URL: KOSync). **Custom Header 1/2** add a `Name: value` header for authentication proxies such as Cloudflare Access; values are masked and obfuscated on the card. Servers that store only a percentage now restore an approximate position instead of nothing. Also in web settings.
- The Filename Fallback Font setting is now **UI Font** (Settings > System > Device): the chosen TrueType family fills characters the built-in font lacks everywhere in the interface (menus, translated labels, dialogs, chapter lists, bookmarks, clippings, stats), not only in filenames and titles. Built-in glyphs and the reading font are unchanged. File Transfer and USB Drive close the font while they run and it reloads afterwards.
- EPUB fieldsets show as outlined boxes with padding; a fieldset that spans pages gets a box on each page, and book CSS (border, margin, padding) overrides the defaults. Light mode and disabled book styles draw no box. Books re-layout once after updating.
- EPUB publisher fonts: books that embed `.ttf`/`.otf` fonts can show them. Settings > Reader > Font Options > Publisher Fonts (also on the in-book Font tab): Off, Ignore Body Font (default; headings and decorative text use the book's fonts, body text keeps yours) or All Text. Needs Embedded Style and is off in Light mode. A face loads only when a page uses it (2 MiB per face, 4 MiB per book) and is kept in the book cache for later opens; books without embedded fonts lay out as before. The web portal's upload settings add Remove Embedded Fonts (off by default) to strip a book's fonts before upload. Books re-layout once after updating.
- EPUB headings (h1-h6) and publisher font sizes (em, rem, %, px, pt, size keywords) now show at their own sizes with built-in and TTF fonts, from 8 to 44 pt; mixed sizes inside a line work too. EPUBs also show publisher drop caps, bordered and shaded blocks, preserved whitespace (`white-space: pre`) and more CSS selectors (ids, child `>` and `::first-letter`). Books re-layout once after updating.
- EPUB headings and publisher font sizes also work with SD `.cpfont` fonts, using the installed sizes nearest to each heading (up to two extra sizes stay loaded). Books re-layout once after updating.
- OPDS: a feed that states its catalog size (`opensearch:totalResults`) shows it after the server name in the header, e.g. "My Library (120)". When the feed also gives `itemsPerPage` and `startIndex` and the page reaches the total, the Next page row and the next-page prefetch are skipped. Feeds without these fields work as before.
- Settings > Display > Ghost Busters (Off, 1-10, default Off): after you open a new menu screen (Home, Library, Settings, the reader's pull-up menu, chapter list and bookmarks, and the screens under them), the panel re-sends that screen this many times as ordinary Fast refreshes to fade ghosts of the previous screen. They start as soon as the screen's own refresh ends (Goodies > Knobs `ghostBusterQuietMs` adds a quiet time first, default 0) and run one after another; any key, tap or new frame pauses them, so a press waits at most for the one refresh already running. Redraws of the same screen (clock, battery, Wi-Fi icon, moving the selection) do not start new ones. Book pages (except the first after opening a book), the sleep and boot screens, the image viewer, the keyboard, transfer screens and Goodies screens never get them, and they never run over a gray (anti-aliased) image. No flashes and no new waveforms: each one is the same Fast refresh any unchanged redraw uses.
- Settings > System > Device > Filename Fallback Font (below Language): pick a TrueType family for characters the built-in UI font lacks in filenames and book titles (Home, File Browser, Library, folder headers). Put static `.ttf` files in `/.crossdink/languages/fonts/<Family>/`; the folder name is the picker label, a regular face is required and bold is optional (up to 32 MiB each; variable fonts, `.otf` and italic-only faces are skipped). Latin and symbols keep the built-in font; menu labels are unchanged. None (default) turns it off. This replaces the old automatic CJK title fallback that borrowed the reader's SD font.
- Settings > System > About shows the device profile, firmware and build, chip, CPU, flash, display and touch controllers, RTC, IMU, SD transport and size, PSRAM size, internal RAM and PSRAM free/minimum/largest block, uptime, reset reason and ESP-IDF version. No network or device identifiers are shown.
- X4 Pro: holding Up and Down together while the device sleeps now shows the date and time large, on every sleep screen, for as long as both keys are held (up to 30 s; a key bounce shorter than 0.1 s does not end it). On release the next sleep screen is drawn (a custom image advances) and the device sleeps again. Shows --:-- if the clock has never been set.
- X4 Pro (debug builds): `POST /api/delete` (Wi-Fi remote token) deletes SD files or folders like File Transfer's delete, also on Goodies > Wi-Fi remote.
- Library: a scan that blocks the screen (first build, Refresh, book actions, or no PSRAM) now counts the books found so far and then says it is sorting, repainting at most every 3 s; Back or a tap cancels it and keeps the previous Library, and the scan is not restarted this visit unless the card changes or you refresh. Background refreshes are unchanged. A card with more books than the Library can hold now says so instead of reporting a generic failure. The Library now indexes up to 32,767 books (was 4,096).
- Home/Reader shortcut on all devices (button shortcuts, Quick Actions, long-press, two-finger swipes, edge slides): returns from nested reader menus straight to the open book, otherwise goes Home. Back/Home is offered next to it in the same lists.
- Select Chapter in every shortcut list (power, chords, long-press, Quick Actions, two-finger swipes): opens the chapter list in EPUB and XTC books. A held side button that opens it no longer scrolls the new list.
- OPDS: each server can save books under the server's own file name (Filename > Server filename), so a book keeps the same name, and its reading progress matches, across devices. The name comes from the download's `Content-Disposition` header and is only used when it is a plain `.epub` name that is safe on FAT (no folders, `..`, leading dot, reserved or invalid characters, at most 240 bytes); otherwise the book gets the usual Author - Title name. When that name is already on the card you are asked before it is replaced.
- OPDS: each server can have its own download folder (server settings > Download Folder, or the web portal). Empty uses the shared default folder, now labelled Default Folder, and `/` saves to the SD root. Folder names are checked on entry: `.`/`..` parts, invalid characters and paths over 63 bytes are refused.
- Fill in missing translations for keys CrossDink already has in 26 languages (German date settings, Polish reading stats, and the rest of the community languages).
- X4 Pro, X4 Classic: Settings and the reader menu follow the physical button layout. The side buttons move between tabs and rows move with the front buttons (X4 Classic) or touch (X4 Pro). Settings > Controls > Menu navigation picks Directional (default) or Legacy, which keeps the old behavior: side buttons move rows and holding them changes tabs.
- Small EPUB images (icons, symbols, drop glyphs) show within the surrounding text line instead of breaking the paragraph; larger images stay centered blocks. Books re-index once.
- Settings > Display > Screen Calibration: move each screen edge (top, right, bottom, left, 0-32 px) until a test border is fully visible, so headers, button hints, lists and reader margins stay clear of the bezel. Buttons or touch (-/+ steppers), Reset to Defaults, Save or Cancel. The values are kept in the device (NVS), not on the SD card, so they stay when the card changes; with nothing saved every screen lays out exactly as before. Saving writes once; drawing reads the values from memory.
- Use static `.otf` fonts, both TrueType-outline and OpenType CFF, alongside `.ttf` files: copy them to `/fonts` or upload them in the web Fonts tab. Variable fonts and collections stay unsupported. The font list rescans once after updating.
- Settings > Reader: the Line spacing, Word spacing and margin sliders show a live text preview of the reader font that updates on each step, on the same partial refresh as the slider.
- Wi-Fi remote: `/api/upload` creates the `path` folder (and any missing parents) when it does not exist yet, so `xink-file put` to a new folder such as `/debug/display` works without opening File Transfer. Only after the token check passes; protected paths are left alone.
- Stats and clippings sync with a CrossPoint Sync server. Settings > System > KOReader Sync is now **Sync Server**, in three sections (Account, What to Sync, Sync Options); the new **Reading Stats** and **Clippings** toggles start OFF (also on the web Settings page) and show Requires CrossPoint Sync on a progress-only server. With either on: Sync Book (a book's long-press menu in Library and Browse Files, EPUB and XTC) and the reader's sync screen show one line each for Progress, Reading Stats, Clippings and All-time Stats; a folder's long-press menu in Browse Files gets **Sync Folder** (the folder and its subfolders, after one confirm); File Transfer gets a **Sync Server** section (Sync Books for the whole card, Sync Reading Stats, Sync Clippings). Bulk syncs run on one screen with the current book, a progress bar and running counts, redrawn with Fast refreshes only; Exit stops between books, and the end lists up to 5 failed books with the reason. Auto Sync's close push also sends the book's stats and clippings in the same Wi-Fi session. Reading Stats > This Device adds Today and 7-day average and a Sync button (Confirm, or the cloud icon in the header on touch). Opening a book in a synced folder that another reader moved further asks "Continue from 45% (Phone)?" (Continue / Stay here); nothing goes on the network at open. Books are queued for the next sync at the reader's held exit writes (sleep, restart, leaving for another screen), never on a page turn.
- Reading stats: active reading time is now also kept per local day (`/.crossdink/daily_reading/`, two 264-byte files per month), for the coming stats and clippings sync to a CrossPoint Sync server. Seconds collect in RAM and are written at the same points as the reader's held exit writes (sleep, restart, leaving for another screen), never on a page turn. New clippings save their creation time as a calendar date when the clock is set.

- Reader menu (button devices) and the pull-down drawer (X4 Pro, Sticky) show the current chapter title under the book title. The drawer leaves the chapter line out when it would push the handle off screen.
- File browser and Library list: a book marked as finished shows a book-with-check icon instead of its file icon (EPUB and XTC). Each row's finished flag is read once when the row is first drawn and kept in memory, so moving the selection reads nothing from the card; marking a book finished or unfinished updates the icon. Library skips the lookup while Hide finished books is on.
- Pull-down (X4 Pro, Sticky): a bug button in the action bar (left of the touchscreen toggle) files a bug report. It saves the screen under the panel, asks you to describe the problem (up to 500 characters), then offers "Include screenshot" and "Include log" before Save; Back throws the report away. Each report is one file, `/bugreports/<date-time>.zip`, holding `report.txt` (your text, firmware, uptime, memory, battery, Wi-Fi, screen, book, chapter and page, font, book and font counts, last battery log row, changed knobs), `log.txt` (the last 64 KB of the log plus any crash report) and `screen.bmp`. Saved Wi-Fi names and passwords, OPDS and KOReader logins, the remote token, URL logins, token/password/key values, auth headers, MAC addresses and public IP addresses are replaced with tags before anything is written; LAN addresses stay. Put an `http://` URL in `/bugreports/url.txt` and each report zip is POSTed there (`?id=<report>`) whenever Wi-Fi is already on; Wi-Fi is never turned on for it, a failed send retries after 5 minutes, and a sent report is renamed `<date-time>.sent.zip` and stays on the card. `scripts/bugreport_receiver.py` is a matching receiver. Release builds now keep a 64 KB log in PSRAM for this (debug builds keep their 512 KB one). `report.txt` also names the running firmware slot, the lowest internal heap since boot, the main task's spare stack, the Wi-Fi address and every numeric setting, and the log ends with a line marking when the report was taken. The web portal's Logs page lists every report zip for download, and debug builds take `CMD:BUGREPORT [text]` over the serial or Wi-Fi remote to file one without touching the device.
- Theme packs on the SD card: put a folder with a `theme.json` in `/.themes/<name>/` or `/themes/<name>/` and pick it under Settings > Display > Theme pack (the row shows once a pack folder exists). A pack names a built-in theme as its `base` (`classic`, `lyra`, `lyra-3-covers`, `lyra-carousel`, `minimal`, `dashboard`, `roundedraff`, `cover-grid`) and changes its sizes and shapes under `metrics` (row heights, gaps, corner radii, selection style, header rule and title alignment, tab bar, popups, keyboard keys; 66 keys named after the theme fields, each kept inside a safe range) and its icons under `icons` (1-bit BMPs, 24 or 32 px: `folder`, `text`, `image`, `book`, `bookmark`, `file`, `recent`, `settings`, `transfer`, `library`, `opds`, `wifi`, `hotspot`, `chart`, `flask`). The pack is read once when picked and at boot, so drawing never reads the card; picking it again reloads an edited pack. A pack cannot change refresh modes, waveforms or anything else about how the panel is driven. A broken pack shows "Theme pack not loaded" and the built-in theme stays (the log names the problem under `[THM]`); picking a built-in theme turns the pack off; two crash reboots in a row with a pack set turn it off and show "Theme pack off after crashes".
- Theme generator: `tools/theme-generator/index.html` is a single page (open it in a browser, no install or network) that builds a theme pack's `theme.json`: pick a base theme (classic and roundedraff are left out: the loader rejects them on touch devices), drag any of the 66 metrics and see a preview laid out like the X4 Pro (480x800, touch) for Settings, Home, popups and the keyboard, then copy or download the file. It writes only the keys the pack loader accepts, only where they differ from the base, and has nothing for refresh modes or waveforms. `sync_defaults.py --check` fails when the page's defaults drift from the C++ tables.

### Changed
- EPUB reader: on a chapter's last page, the images on the next chapter's first page are prepared in the background while you read, and on a chapter's first page those on the previous chapter's last page, so turning into a chapter (including single-page chapters with an illustration) shows its image at once instead of a placeholder and a redraw. Needs that chapter's layout already cached (the next one is prepared near the end of the chapter, except for very large chapters).
- X4 Pro and X4 Classic: the 120-145 ms panel controller check runs once per device and its answer is saved, so later boots and wakes skip it. A full flash erase, or a flash image copied from another device, checks again, and so does waking with Down held (the recovery firmware chord), e.g. after a panel swap.
- EPUB: opening a book no longer holds key and touch handling while the SD reading font loads (up to about 0.7 s); the font now loads with the first page. The first page appears as fast as before.
- OPDS: catalogs are one continuous list per feed instead of pages with Next/Previous rows. The next page is fetched in the background and appended as you scroll or step towards the end of the list, with no limit on the number of pages (2000 rows stay in memory around your position; pages scrolled far away re-parse from the cache when you come back; the header still shows the catalog total). A page that is not cached yet shows its first rows as soon as they arrive instead of after the whole page has downloaded; the rest fills in silently, Back and taps work meanwhile, and the download starts while the Loading frame is still drawing. Back returns to the row you opened, pulling the pages before it from the cache.
