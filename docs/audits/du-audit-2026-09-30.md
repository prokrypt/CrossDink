zero for the OLD plane actually supplied (UltraChipLutBalance.h gate), or the
panel's OTP waveform runs with the true previous frame in DTM1.

## feat/goodies-wifi-0930-0al3z4 @ 70901e15 (SDK a3a2a6a): reachable unsafe items

1. Every HALF refresh: DTM1 = complement of the target, so the OTP GC re-drives
   every white pixel K->W and every black W->K (fixed by SDK 8fab43b).
   Reached by the reader cleanup cadence, reader entry, image pages, sleep
   screens, Night Mode toggle, every Display test. Not avoidable in normal use.
2. KBDEXP bit 4 (CMD:KBDEXP over serial or /api/cmd): old one-way DU LUT,
   KW VDL only, WK VDH only, KK VDH re-drive on every held black.
3. Goodies > Display test built-ins with DU: "Refresh modes", "Ghost pick (8
   squares)", "DU frames sweep", "DU scrub 15 over text", "DU scrub 20 over
   text (cold panel)"; any SD /debug/display/*.txt with `refresh du` or
   `scrub du`.
4. First B/W paint after a direct-gray sleep image without a reboot:
   complement DTM1 + OTP Fast (one-way). Rare: sleep normally ends in deep sleep.
5. Text AA / image AA / BMP gray / PRE_BW_MID: same as 5513dc2.

Safe on 70901e15: Turbo keyboard default (flags 67, OTP Fast, no DU).
